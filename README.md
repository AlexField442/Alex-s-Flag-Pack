# Alex's Flag Pack (prov. title)
This is a work-in-progress mod for the video game _Hearts of Iron IV_ that attempts to upgrade all of the 'full-sized' flags from 82x52 to 328x208 resolution, allowing them to look much better on high-resolution displays.

 - **Current Mod Version:** Alpha 6 (8/10/26)
 - **Current Game Version:** Operation Postern (v1.19.2.0)
